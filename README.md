# CompanionPets

> Companion pet hatching, care, training, and play for TF-Minecraft.

CompanionPets is an early plugin scaffold. Its design covers pets with individual
needs, favourite toys, and learned tricks. The current plugin only logs its
startup and shutdown; the pet systems are not implemented yet.
