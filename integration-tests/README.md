# CompanionPets Paper integration checks

The dev-only helper exercises CompanionPets on Paper with the configured provider
plugins. CI compiles the helper; execution needs a separate dev-server run.

Build, installation, cleanup, and result instructions are in the
[testing guide](https://github.com/TF-Minecraft/Docs/blob/main/projects/CompanionPets/docs/testing.md).

Technical documentation is maintained in [TF-Minecraft/Docs](https://github.com/TF-Minecraft/Docs).
